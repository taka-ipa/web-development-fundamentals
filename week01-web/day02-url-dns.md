# Day02 URLとDNS

1.URLのスキーム・ホスト名・パス・クエリパラメータの役割をそれぞれ説明してください。
・スキーム　https等の通信方式
・ホスト名　example.com接続先を示す
・ポート番号　433等のポート番号
・パス　/users/10
・クエリ　サーバーに渡す追加クエリ（?id=10）とか


2.DNSとは何ですか？ なぜDNSが必要なのか説明してください。
・人間が覚えやすいドメイン名から、通信に必要なIPアドレスを調べる仕組み
・example.com という名前だけでは、ブラウザは接続先のIPアドレスをまだ知らない場合があるのでDNSが必要。

3.ブラウザに https://example.com と入力したとき、DNSを利用してサーバーへ接続するまでの流れを説明してください。
・IPアドレスを問い合わせる。
・DNSで接続先のIPアドレスを調べる。
・ブラウザにIPアドレスを返してサーバーへ接続

4.DNSとHTTPの役割にはどのような違いがありますか？
・DNSはIPアドレスを調べる。
・HTTPはwebデータを取得する


5.nslookup と curl -I は、それぞれ何を確認するためのコマンドですか？
・nslookupはドメイン名とIPアドレスの対応関係（DNS情報）をDNSサーバーに直接問い合わせて確認したい時に使います。
nslookup example.com（ドメインから）かnslookup 93.184.216.34（IPアドレスから）
・curl -Iはサーバーから HTTP レスポンスの「ヘッダー（Header）のみ」を取得するためのオプション。
-iだとボディも取得。
