# Day04 REST API
1.HTTPステータスコードとは何ですか？ また、2xx・4xx・5xxの違いを説明してください。
・HTTPリクエストを送って、レスポンスが返ってきた時に処理が成功したか、失敗したかを数字で伝えるもの。
・2xx　成功
・4xx　クライアントエラー
・5xx　サーバーエラー

2.401と403の違いを、具体例を使って説明してください。
・401　ログインしていない状態で認証必須APIにアクセス
・403　ログイン済だけど他人の管理画面を操作する権限がない時

3.200と201の違いは何ですか？ それぞれどんなAPIで使われますか？
・200　リクエストが成功している。APIアクセス時
・201　データが新規作成された時。リクエストの時

4.Laravelのバリデーションで422が返ってきました。これはどんな状態ですか？ Next.js側ではどのように対応すべきですか？
入力内容が間違っている可能性があるので、バリデーション内容を確認する。

5.Next.jsからLaravelのAPIを呼び出したところ500エラーが返ってきました。原因として何が考えられ、どのように調査しますか？
500はサーバー内部でエラーが発生した状態です。Laravelのコードの不具合やデータベース接続エラーなどが考えられます。まずブラウザの開発者ツールで失敗したAPIを確認し、次にLaravelのログを調査して原因を特定します。
